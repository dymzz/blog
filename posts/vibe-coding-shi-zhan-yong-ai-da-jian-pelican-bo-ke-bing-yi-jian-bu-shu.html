Vibe Coding 实战：用 AI 搭建 Pelican 博客并一键部署

Vibe Coding AI Pelican GitHub Pages 自动化

Vibe Coding 是一种以自然语言驱动的编程方式——你只需描述意图，AI 负责生成代码。本文记录一次真实的 Vibe Coding 过程：为 Pelican 博客编写一键部署脚本并完成 GitHub Pages 配置。

起因¶

Pelican 博客项目已经搭好，内容也有了，但每次发布都要手动执行构建、切换分支、推送文件，流程繁琐。目标是：一行命令完成部署。

第一步：描述需求¶

我向 AI 说了一句：

快速部署脚本

就这么简单。AI 开始自动分析项目结构。

第二步：AI 主动理解上下文¶

AI 做了以下事情：

  1. 读取项目目录——发现这是 Pelican 博客项目
  2. 读取配置文件——pelicanconf.py、publishconf.py、pyproject.toml
  3. 理解构建方式——Pelican 使用 pelican 命令生成静态站点，publishconf.py 用于生产环境

这一步没有任何人工指导，AI 通过文件内容自行推断。

第三步：AI 询问关键决策¶

AI 发现部署目标不唯一，主动提问：

你想部署到哪个平台？
- GitHub Pages
- VPS/服务器
- 仅本地生成

我选择了 GitHub Pages。这是 Vibe Coding 的核心模式：AI 负责细节，人负责决策。

第四步：生成部署脚本¶

AI 生成了 deploy.sh：

#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
OUTPUT_DIR="$SCRIPT_DIR/output"
BRANCH="gh-pages"

echo "==> 安装依赖..."
pip install pelican markdown

echo "==> 生成静态站点..."
pelican "$SCRIPT_DIR/content" -o "$OUTPUT_DIR" -s "$SCRIPT_DIR/publishconf.py"

echo "==> 部署到 GitHub Pages ($BRANCH)..."
if [ ! -d "$OUTPUT_DIR/.git" ]; then
    git -C "$OUTPUT_DIR" init
fi

git -C "$OUTPUT_DIR" checkout --orphan "$BRANCH" 2>/dev/null || git -C "$OUTPUT_DIR" checkout "$BRANCH"
git -C "$OUTPUT_DIR" add -A
git -C "$OUTPUT_DIR" commit -m "Deploy: $(date +%Y-%m-%d %H:%M:%S)" --allow-empty

REMOTE_URL=$(git -C "$SCRIPT_DIR" remote get-url origin 2>/dev/null || echo "")
if [ -n "$REMOTE_URL" ]; then
    git -C "$OUTPUT_DIR" remote add origin "$REMOTE_URL" 2>/dev/null || git -C "$OUTPUT_DIR" remote set-url origin "$REMOTE_URL"
    git -C "$OUTPUT_DIR" push -f origin "$BRANCH"
    echo "==> 部署完成！"
else
    echo "==> 未检测到 remote origin，请手动推送 output 目录到 $BRANCH 分支"
fi

脚本逻辑清晰：

  1. 安装 Pelican 依赖
  2. 用 publishconf.py 生成生产环境站点
  3. 在 output/ 目录初始化 Git，提交到 gh-pages 分支
  4. 自动检测远程仓库并推送

第五步：追问配置细节¶

我继续问 GitHub Pages 还需要配置什么，AI 回答了三个步骤：

  1. Source: Deploy from a branch
  2. Branch: gh-pages，目录 / (root)
  3. 点 Save

当遇到 "Add a verified domain" 步骤时，AI 明确告知这是可选的：

  • 不配自定义域名 → 直接用 github.io 地址
  • 要配自定义域名 → 填域名 + CNAME 记录 + 开启 HTTPS

第六步：生成文章记录过程¶

最后，我让 AI 把整个过程写成一篇博客文章。就是你正在读的这篇。

Vibe Coding 的体会¶

传统编程 Vibe Coding
自己写每一行代码 描述意图，AI 生成代码
手动查阅文档 AI 自动读取项目文件
反复试错 AI 一次生成可用方案
自己找配置方法 AI 主动告知注意事项

核心理念：人提供方向和决策，AI 处理实现细节。你不需要知道 checkout --orphan 的语法，只需要说"部署到 GitHub Pages"。

未来的编程不是写代码，而是写意图。
